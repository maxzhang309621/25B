# 经验总结：2025 B 题碳化硅外延层厚度的确定

## 算法选型结论

| 步骤 | 最终采用 | 被否决/降级的候选 | 结论与原因 |
|---|---|---|---|
| 光谱坐标 | 直接在等间距波数域处理 | 先转波长再普通 FFT | 波长轴会变成不等间距，未经重采样使用 FFT 会产生周期偏差 |
| 预处理 | 双尺度 Savitzky–Golay | 单一强平滑、强制裁剪反射率 | 双尺度方法保留峰位；裁剪附件 2 的 >100% 数据会人为改变峰形 |
| 双光束初值 | 波数域 FFT | 单独依赖局部峰距 | FFT 不易因单个漏峰改变干涉级次，但只作为粗估 |
| 双光束主估计 | 峰、谷序列 Theil–Sen 稳健回归 | 宽波段常折射率余弦全谱最优值 | 宽波段真实色散会使常折射率全谱拟合跳到邻近级次；极值序列更可解释、更稳定 |
| 多光束模型 | Airy/Fresnel 形状 + 全局搜索和有界精修 | 从任意初值直接局部最小二乘 | 厚度目标函数多峰，直接局部拟合容易落入错误干涉级次 |
| 多光束判定 | 谐波、有效反射率、AICc/RMSE 三重证据 | 只看拟合误差或只看有效反射率 | 额外 Airy 参数可吸收色散/基线误差，单一拟合改善会把 SiC 误判为多光束 |
| 不确定度 | 峰、谷间距分组重采样并对齐点估计 | 无约束残差区块重采样 | 残差重采样会偶发干涉级次别名，形成不代表局部测量误差的远端模式 |

## 踩坑记录

1. **宽波段相位漂移**
   - 现象：SiC 峰谷公式给出约 \(7.9\,\mu\mathrm m\)，常折射率全谱余弦拟合却偏到约 \(8.6\,\mu\mathrm m\)。
   - 根因：真实折射率随波数变化，数千波数范围内累积相位误差会让错误级次获得更低残差。
   - 解法：以峰谷稳健回归为主结果，全谱精修只允许在主解附近小幅移动，越界时回退。

2. **Airy 过拟合造成 SiC 假阳性**
   - 现象：Airy 模型显著降低 SiC 残差，但厚度移动到不合理的邻近解。
   - 根因：有效反射率和相位参数同时吸收了基线、色散和振幅衰减。
   - 解法：限制厚度搜索到双光束物理解附近，并要求高次谐波证据与模型改善同时成立。

3. **重采样区间偏离点估计**
   - 现象：间距均值重采样区间可能不包含 Theil–Sen 点估计。
   - 根因：区间中心和点估计使用不同统计量。
   - 解法：保留重采样离散度，将分布中心校正到最终稳健点估计，并在系统测试中检查区间包含性。

4. **数据值超过物理百分比**
   - 现象：附件 2 最大反射率约为 102.74%。
   - 根因：更可能是仪器参考/基线校准偏差，而非真实能量反射率。
   - 解法：不静默裁剪；完整审计并允许模型使用慢变基线与幅度校准，厚度主估计仍依赖峰位。

5. **流程稳定节点缺失**
   - 现象：实现和测试均通过，但无法提交或打 tag。
   - 根因：工作区不是 Git 仓库。
   - 解法：记录所有运行命令和结果，不擅自初始化仓库；若后续需要版本节点，由用户明确要求后建立版本控制。

## 可复用组件

- `src/data_io.py`：双列光谱 Excel 的 schema 校验、异常首点、排序和审计。
- `src/preprocess.py`：以物理波数宽度配置 Savitzky–Golay 窗口，适用于不同采样间隔。
- `src/optics.py`：Snell 折射角、薄膜相位坐标、条纹间距厚度公式和 Airy 核。
- `src/two_beam.py`：FFT 粗估 + 峰谷稳健回归 + 局部相位精修的薄膜厚度模板。
- `src/multi_beam.py`：变量投影式 Airy 拟合和多峰参数搜索框架。
- `src/diagnostics.py`：谐波证据、信息准则和误差改善的联合模型判定。
- `src/uncertainty.py`：条纹间距分组重采样和双角度一致性指标。
- `src/test_model.py`：用已知厚度合成光谱验证反演算法的测试模式。

## 流程改进建议

1. 架构阶段应把“材料专属光学常数是否已知”列为前置数据检查；若未知，验收标准应明确区分统计误差和光学常数系统误差。
2. 算法选型阶段应优先核对参考折射率数据的波段覆盖，禁止把可见/近红外公式无说明地外推到中远红外。
3. 对周期型反问题，测试标准应增加“相邻级次别名”用例；仅用无噪声单一合成数据不足以发现跳级问题。
4. 多模型判定应在架构中预先规定独立证据，避免实现阶段根据拟合结果临时选择对自己有利的阈值。
5. 流水线的提交/tag 步骤应先检查仓库是否存在；不存在时记录为环境限制，不应自动初始化仓库。
