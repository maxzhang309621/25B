# 经验总结：2025 B 题碳化硅外延层厚度的确定

## 算法选型结论

| 步骤 | 最终采用 | 被否决/降级的候选 | 结论与原因 |
|---|---|---|---|
| 光谱坐标 | 直接在等间距波数域处理 | 先转波长再普通 FFT | 波长轴会变成不等间距，未经重采样使用 FFT 会产生周期偏差 |
| 预处理 | 双尺度 Savitzky–Golay | 单一强平滑、强制裁剪反射率 | 双尺度方法保留峰位；裁剪附件 2 的 >100% 数据会人为改变峰形 |
| 双光束初值 | 波数域 FFT | 单独依赖局部峰距 | FFT 不易因单个漏峰改变干涉级次，但只作为粗估 |
| 双光束主估计 | 峰、谷序列 Theil–Sen 稳健回归 | 宽波段常折射率余弦全谱最优值 | 宽波段真实色散会使常折射率全谱拟合跳到邻近级次；极值序列更可解释、更稳定 |
| 多光束模型 | Airy/Fresnel 形状 + 全局搜索和有界精修 | 从任意初值直接局部最小二乘 | 厚度目标函数多峰，直接局部拟合容易落入错误干涉级次 |
| 多光束判定 | 谐波、有效反射率、AICc/RMSE 三重证据 | 只看拟合误差或只看有效反射率 | 额外 Airy 参数可吸收色散/基线误差，单一拟合改善会把 SiC 误判为多光束 |
| 不确定度 | 峰、谷间距分组重采样并对齐点估计 | 无约束残差区块重采样 | 残差重采样会偶发干涉级次别名，形成不代表局部测量误差的远端模式 |

## 踩坑记录

1. **宽波段相位漂移**
   - 现象：SiC 峰谷公式给出约 \(7.9\,\mu\mathrm m\)，常折射率全谱余弦拟合却偏到约 \(8.6\,\mu\mathrm m\)。
   - 根因：真实折射率随波数变化，数千波数范围内累积相位误差会让错误级次获得更低残差。
   - 解法：以峰谷稳健回归为主结果，全谱精修只允许在主解附近小幅移动，越界时回退。

2. **Airy 过拟合造成 SiC 假阳性**
   - 现象：Airy 模型显著降低 SiC 残差，但厚度移动到不合理的邻近解。
   - 根因：有效反射率和相位参数同时吸收了基线、色散和振幅衰减。
   - 解法：限制厚度搜索到双光束物理解附近，并要求高次谐波证据与模型改善同时成立。

3. **重采样区间偏离点估计**
   - 现象：间距均值重采样区间可能不包含 Theil–Sen 点估计。
   - 根因：区间中心和点估计使用不同统计量。
   - 解法：保留重采样离散度，将分布中心校正到最终稳健点估计，并在系统测试中检查区间包含性。

4. **数据值超过物理百分比**
   - 现象：附件 2 最大反射率约为 102.74%。
   - 根因：更可能是仪器参考/基线校准偏差，而非真实能量反射率。
   - 解法：不静默裁剪；完整审计并允许模型使用慢变基线与幅度校准，厚度主估计仍依赖峰位。

5. **流程稳定节点缺失**
   - 现象：实现和测试均通过，但无法提交或打 tag。
   - 根因：工作区不是 Git 仓库。
   - 解法：记录所有运行命令和结果，不擅自初始化仓库；若后续需要版本节点，由用户明确要求后建立版本控制。

## 流程改进建议

1. 架构阶段应把“材料专属光学常数是否已知”列为前置数据检查；若未知，验收标准应明确区分统计误差和光学常数系统误差。
2. 算法选型阶段应优先核对参考折射率数据的波段覆盖，禁止把可见/近红外公式无说明地外推到中远红外。
3. 对周期型反问题，测试标准应增加“相邻级次别名”用例；仅用无噪声单一合成数据不足以发现跳级问题。
4. 多模型判定应在架构中预先规定独立证据，避免实现阶段根据拟合结果临时选择对自己有利的阈值。
5. 流水线的提交/tag 步骤应先检查仓库是否存在；不存在时记录为环境限制，不应自动初始化仓库。

## v2 可视化增强经验

1. **证据图应直接消费诊断对象**：绘图层不应重新实现谐波或模型判定，否则图片与 CSV 可能产生口径漂移。本次把频谱计算提取为 `diagnostics.harmonic_spectrum`，由诊断和绘图共用。
2. **复杂模型不能只展示更低残差**：将峰谷、频谱、高次谐波、有效反射率、RMSE、AICc 和最终模型放在同一张图中，才能说明“为什么选这个模型”。
3. **跨量级结果应分面比较**：SiC 约 7.9 µm、Si 约 3.6 µm；共用单纵轴会压缩各组差异。按材料分面后，角度差、模型差和置信区间更清楚。
4. **判据图必须显示失败项**：SiC 虽然三项指标通过，但谐波项失败；二元证据矩阵能直观表达“全部通过才判多光束”，比只画综合结论更可审计。
5. **可复用组件**：
   - `plot_spectrum_fit`：单光谱六区证据链模板；
   - `plot_thickness_comparison`：模型值与非对称区间分面图；
   - `plot_multibeam_evidence`：多指标阈值证据矩阵；
   - `plot_model_quality`：嵌套模型误差改善对比。

## v3 波长—载流子浓度耦合经验

### 算法选型结论

| 步骤 | 最终采用 | 被否决/降级的候选 | 结论与原因 |
|---|---|---|---|
| Si 背景色散 | Edwards–Ochoa 中远红外式 | 可见/近红外 Sellmeier 外推 | 只有前者完整覆盖 2.5–25 µm 赛题范围 |
| SiC 物性 | 晶格振子 + 自由载流子复介电 | 全波段常数实折射率 | 常数模型无法描述 Reststrahlen 区和掺杂载流子响应 |
| 界面模型 | 外延层/衬底分别建模的 Fresnel–Airy | 单一有效反射率解释物性 | 分层模型能显式表达掺杂差造成的界面反射 |
| 参数估计 | 共享厚度、仅开放两个浓度参数 | 同时自由拟合浓度、迁移率、有效质量和声子参数 | 四条光谱不足以支持高维物性反演 |
| 浓度结论 | 可辨识性门控 + 固定情景回退 | 直接报告优化器最优浓度 | 更低训练误差不代表浓度被数据唯一识别 |
| 稳定性 | 连续三波段留出厚度 | 随机留点验证 | 相邻光谱点高度相关，随机留点会高估泛化能力 |

### 踩坑记录

1. **先验正则化最优点不一定优于固定情景**：自由浓度拟合同时考虑论文先验，训练 RMSE 可能高于某个固定情景。最终增加情景对照门槛，避免把“正则化折中点”误报为实测浓度。
2. **全谱更复杂不等于更可靠**：SiC 复介电模型在全谱可获得较低误差，但三个连续波段厚度变化约 8.69%，说明当前简化晶型/吸收模型仍不足。程序必须回退稳健基线。
3. **参数触边是物理信息而非优化成功**：Si 衬底浓度达到上界，虽然厚度留段稳定，浓度仍只能解释为“高掺杂情景”，不能给出唯一数值。
4. **统计误差与物性误差量级不同**：重采样区间较窄，而未知掺杂情景造成的厚度范围明显更宽；两者必须分栏报告。

### 可复用组件

- `src/dispersion.py`：材料色散策略、自由载流子复介电项、浓度相关迁移率和被动平方根。
- `src/optics.py::thin_film_reflectance`：复介质斜入射单层 Fresnel–Airy 核。
- `src/joint_calibration.py`：多角度共享物理参数、线性干扰参数剖面消元、可辨识性门控和情景回退。
- `output/refractive_index_curves.csv`：外延层/衬底 \(n,k\) 曲线的可审计导出格式。

### 流程改进建议

1. 物性反演项目应在建模前主动索取晶型、晶向、温度、n/p 型、外延层与衬底掺杂浓度；缺失时从一开始就设计情景输出。
2. “算法能拟合”与“参数可辨识”应作为两个独立验收项，测试报告必须列出边界命中、参数相关性和留段稳定性。
3. 对连续光谱应优先采用连续留段或留一角度预测，不能用随机划分代替外推验证。
4. 后续若获得 Hall/C–V 测量，应固定或收紧浓度先验后重跑，而不是继续增加自由参数。

## v4 可视化与流程图经验

1. **统计区间与系统范围必须使用不同视觉语义**：窄误差棒表示条件统计区间，宽半透明区间表示掺杂情景系统误差，避免读者把两者误认为同一种置信区间。
2. **复杂门控需要同时展示数值和去向**：仅画 CV/偏移柱形不足以解释最终结果；图中还需明确“浓度不可辨识”“参数触边”和“采用固定情景/回退基线”。
3. **曲线、情景和门控应分图表达**：复折射率、厚度情景、RMSE 与可辨识性单位不同，拆为三张图比堆叠到单一大图更适合论文引用。
4. **流程图保留双格式**：Mermaid 便于编辑和审稿修改，Matplotlib PNG 可由项目入口离线复现并直接插入论文。
5. **可复用组件**：
   - `plot_dispersion_curves`：分层复折射率曲线模板；
   - `plot_carrier_scenarios`：物性情景—结果—误差比较模板；
   - `plot_identifiability_diagnostics`：连续留段与阈值门控图；
   - `plot_model_flowchart`：无 Graphviz 依赖的论文流程图生成模板。

## v5 增强反射率浓度反演经验

1. **绝对标定资格必须先于参数优化**：附件 2 有 3.51% 点超过 100%。若不先标记 `relative_shape`，优化器可利用增益参数给出看似精确但不可解释的绝对浓度。
2. **慢变仪器项会与自由载流子响应竞争**：删除每角度独立的 `z×R` 项，改用共享漂移和有界增益/偏置后，仪器参数更可审计。
3. **厚度必须独立锚定**：当厚度允许自由移动时，浓度轮廓会通过厚度补偿获得虚假窄区间；收紧到稳健厚度附近后，真实数据立即暴露厚度触边和固定情景改善不足。
4. **轮廓区间优于局部协方差**：衬底浓度的条件区间直接触及先验下界，清楚表明只能得到单侧/情景约束；局部相关系数本身无法揭示这一问题。
5. **主表与诊断候选必须分离**：未通过门控时 `epi_carrier_cm3`、`substrate_carrier_cm3` 写为 `null/NaN`，优化候选只保存在明确命名的诊断字段中。
6. **可复用组件**：
   - `instrument_response.py`：光谱资格、材料波段权重和受约束仪器响应；
   - `carrier_inference.py`：多起点物理拟合、固定情景比较和轮廓区间；
   - `plot_carrier_profiles`：参数边界与条件可信区间可视化。
