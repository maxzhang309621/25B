# 经验总结：2025 B 题碳化硅外延层厚度的确定

## 算法选型结论

| 步骤 | 最终采用 | 被否决/降级的候选 | 结论与原因 |
|---|---|---|---|
| 光谱坐标 | 直接在等间距波数域处理 | 先转波长再普通 FFT | 波长轴会变成不等间距，未经重采样使用 FFT 会产生周期偏差 |
| 预处理 | 双尺度 Savitzky–Golay | 单一强平滑、强制裁剪反射率 | 双尺度方法保留峰位；裁剪附件 2 的 >100% 数据会人为改变峰形 |
| 双光束初值 | 波数域 FFT | 单独依赖局部峰距 | FFT 不易因单个漏峰改变干涉级次，但只作为粗估 |
| 双光束主估计 | 峰、谷序列 Theil–Sen 稳健回归 | 宽波段常折射率余弦全谱最优值 | 宽波段真实色散会使常折射率全谱拟合跳到邻近级次；极值序列更可解释、更稳定 |
| 多光束模型 | Airy/Fresnel 形状 + 全局搜索和有界精修 | 从任意初值直接局部最小二乘 | 厚度目标函数多峰，直接局部拟合容易落入错误干涉级次 |
| 多光束判定 | 谐波、有效反射率、AICc/RMSE 三重证据 | 只看拟合误差或只看有效反射率 | 额外 Airy 参数可吸收色散/基线误差，单一拟合改善会把 SiC 误判为多光束 |
| 不确定度 | 峰、谷间距分组重采样并对齐点估计 | 无约束残差区块重采样 | 残差重采样会偶发干涉级次别名，形成不代表局部测量误差的远端模式 |

## 踩坑记录

1. **宽波段相位漂移**
   - 现象：SiC 峰谷公式给出约 \(7.9\,\mu\mathrm m\)，常折射率全谱余弦拟合却偏到约 \(8.6\,\mu\mathrm m\)。
   - 根因：真实折射率随波数变化，数千波数范围内累积相位误差会让错误级次获得更低残差。
   - 解法：以峰谷稳健回归为主结果，全谱精修只允许在主解附近小幅移动，越界时回退。

2. **Airy 过拟合造成 SiC 假阳性**
   - 现象：Airy 模型显著降低 SiC 残差，但厚度移动到不合理的邻近解。
   - 根因：有效反射率和相位参数同时吸收了基线、色散和振幅衰减。
   - 解法：限制厚度搜索到双光束物理解附近，并要求高次谐波证据与模型改善同时成立。

3. **重采样区间偏离点估计**
   - 现象：间距均值重采样区间可能不包含 Theil–Sen 点估计。
   - 根因：区间中心和点估计使用不同统计量。
   - 解法：保留重采样离散度，将分布中心校正到最终稳健点估计，并在系统测试中检查区间包含性。

4. **数据值超过物理百分比**
   - 现象：附件 2 最大反射率约为 102.74%。
   - 根因：更可能是仪器参考/基线校准偏差，而非真实能量反射率。
   - 解法：不静默裁剪；完整审计并允许模型使用慢变基线与幅度校准，厚度主估计仍依赖峰位。

5. **流程稳定节点缺失**
   - 现象：实现和测试均通过，但无法提交或打 tag。
   - 根因：工作区不是 Git 仓库。
   - 解法：记录所有运行命令和结果，不擅自初始化仓库；若后续需要版本节点，由用户明确要求后建立版本控制。

## 流程改进建议

1. 架构阶段应把“材料专属光学常数是否已知”列为前置数据检查；若未知，验收标准应明确区分统计误差和光学常数系统误差。
2. 算法选型阶段应优先核对参考折射率数据的波段覆盖，禁止把可见/近红外公式无说明地外推到中远红外。
3. 对周期型反问题，测试标准应增加“相邻级次别名”用例；仅用无噪声单一合成数据不足以发现跳级问题。
4. 多模型判定应在架构中预先规定独立证据，避免实现阶段根据拟合结果临时选择对自己有利的阈值。
5. 流水线的提交/tag 步骤应先检查仓库是否存在；不存在时记录为环境限制，不应自动初始化仓库。

## v3 波长—载流子浓度耦合经验

### 算法选型结论

| 步骤 | 最终采用 | 被否决/降级的候选 | 结论与原因 |
|---|---|---|---|
| Si 背景色散 | Edwards–Ochoa 中远红外式 | 可见/近红外 Sellmeier 外推 | 只有前者完整覆盖 2.5–25 µm 赛题范围 |
| SiC 物性 | 晶格振子 + 自由载流子复介电 | 全波段常数实折射率 | 常数模型无法描述 Reststrahlen 区和掺杂载流子响应 |
| 界面模型 | 外延层/衬底分别建模的 Fresnel–Airy | 单一有效反射率解释物性 | 分层模型能显式表达掺杂差造成的界面反射 |
| 参数估计 | 共享厚度、仅开放两个浓度参数 | 同时自由拟合浓度、迁移率、有效质量和声子参数 | 四条光谱不足以支持高维物性反演 |
| 浓度结论 | 可辨识性门控 + 固定情景回退 | 直接报告优化器最优浓度 | 更低训练误差不代表浓度被数据唯一识别 |
| 稳定性 | 连续三波段留出厚度 | 随机留点验证 | 相邻光谱点高度相关，随机留点会高估泛化能力 |

### 踩坑记录

1. **先验正则化最优点不一定优于固定情景**：自由浓度拟合同时考虑论文先验，训练 RMSE 可能高于某个固定情景。最终增加情景对照门槛，避免把“正则化折中点”误报为实测浓度。
2. **全谱更复杂不等于更可靠**：SiC 复介电模型在全谱可获得较低误差，但三个连续波段厚度变化约 8.69%，说明当前简化晶型/吸收模型仍不足。程序必须回退稳健基线。
3. **参数触边是物理信息而非优化成功**：Si 衬底浓度达到上界，虽然厚度留段稳定，浓度仍只能解释为“高掺杂情景”，不能给出唯一数值。
4. **统计误差与物性误差量级不同**：重采样区间较窄，而未知掺杂情景造成的厚度范围明显更宽；两者必须分栏报告。

- `src/optics.py::thin_film_reflectance`：复介质斜入射单层 Fresnel–Airy 核。
- `src/joint_calibration.py`：多角度共享物理参数、线性干扰参数剖面消元、可辨识性门控和情景回退。

### 流程改进建议

1. 物性反演项目应在建模前主动索取晶型、晶向、温度、n/p 型、外延层与衬底掺杂浓度；缺失时从一开始就设计情景输出。
2. “算法能拟合”与“参数可辨识”应作为两个独立验收项，测试报告必须列出边界命中、参数相关性和留段稳定性。
3. 对连续光谱应优先采用连续留段或留一角度预测，不能用随机划分代替外推验证。
4. 后续若获得 Hall/C–V 测量，应固定或收紧浓度先验后重跑，而不是继续增加自由参数。

## v4 可视化与流程图经验

1. **统计区间与系统范围必须使用不同视觉语义**：窄误差棒表示条件统计区间，宽半透明区间表示掺杂情景系统误差，避免读者把两者误认为同一种置信区间。

## v5 增强反射率浓度反演经验

1. **绝对标定资格必须先于参数优化**：附件 2 有 3.51% 点超过 100%。若不先标记 `relative_shape`，优化器可利用增益参数给出看似精确但不可解释的绝对浓度。
2. **慢变仪器项会与自由载流子响应竞争**：删除每角度独立的 `z×R` 项，改用共享漂移和有界增益/偏置后，仪器参数更可审计。
3. **厚度必须独立锚定**：当厚度允许自由移动时，浓度轮廓会通过厚度补偿获得虚假窄区间；收紧到稳健厚度附近后，真实数据立即暴露厚度触边和固定情景改善不足。
4. **轮廓区间优于局部协方差**：衬底浓度的条件区间直接触及先验下界，清楚表明只能得到单侧/情景约束；局部相关系数本身无法揭示这一问题。
5. **主表与诊断候选必须分离**：未通过门控时 `epi_carrier_cm3`、`substrate_carrier_cm3` 写为 `null/NaN`，优化候选只保存在明确命名的诊断字段中。
6. **可复用组件**：
   - `instrument_response.py`：光谱资格、材料波段权重和受约束仪器响应；
   - `carrier_inference.py`：多起点物理拟合、固定情景比较和轮廓区间；
   - `plot_carrier_profiles`：参数边界与条件可信区间可视化。

## v6 论文原始数据图经验

1. **综合诊断图与论文原始图承担不同职责**：综合图适合说明判定过程，但不适合逐项引用；论文素材应由同一计算结果另行生成单指标单图。
2. **图例外置比自动 `best` 更稳定**：独立原始图使用固定图外区域后，不会覆盖曲线峰谷，也避免不同数据重跑后图例位置漂移。
3. **标签清晰不能只靠增大字号**：数据标签需交替偏移、增加白底并同步扩展坐标留白，否则更大字号会加剧遮挡。
4. **物理量拆分优于多面板放大**：SiC 与 Si 的 \(n,k\) 分材料、分分量输出，既保留曲线细节，也使每张图片具有唯一引用语义。
5. **禁止分析文字应成为自动检查项**：独立图生成模块不接收判定状态，并对 PASS/FAIL、阈值、结论、回退和可辨识等级执行源码约束检查，可降低后续修改误混入分析文字的风险。
6. **可复用组件**：
   - `raw_evidence_plotting.py::plot_raw_multibeam_evidence`：标量证据及频谱的批量单图导出；
   - `raw_evidence_plotting.py::plot_raw_dispersion_evidence`：色散、情景、稳定性和轮廓的单图导出；
   - `_external_legend` 与 `_save`：固定图外图例、高清 PNG 和紧凑边界的统一模板。

## v7 方案 B 本征色散三轨经验

### 算法选型结论

| 步骤 | 最终采用 | 被否决的候选 | 否决原因 |
|---|---|---|---|
| 本征色散厚度 | 透明区相位模型 + 正余弦变量投影 + 粗网格/有界精修 | 本征介电函数直接代入完整 Fresnel 反射拟合 | 外延层与衬底本征介电函数相同时层间反射退化，厚度不可由绝对反射幅值识别 |
| 掺杂影响 | low/medium/high 固定情景包络 | 自由优化浓度作为方案 B 主参数 | 现有光谱不能唯一识别两层浓度，且会与厚度和仪器项补偿 |
| 结果选择 | 三轨显式采纳规则 | 按 RMSE 自动选择轨道 | 多参数模型更易降低残差，但不代表参数可解释 |
| 不可辨识验证 | 复用既有指标并聚合成证据 JSON | 重新拟合一套独立审计模型 | 会产生阈值与数值口径漂移 |

### 踩坑记录

1. **“本征色散”不等于“完整膜反射模型仍可测厚”**：若两层使用同一介电函数，下界面反射消失。解决方式是明确方案 B 只研究相位中色散对厚度的影响，振幅由变量投影吸收。
2. **厚度相位目标多峰**：直接使用单次有界标量优化可能落入错误级次。最终采用固定网格粗定位后再局部精修。
3. **审计原因不能人为凑数**：SiC 有三项以上独立失败证据；Si 目前只有触边和固定情景比较失败。报告应忠实输出实际失败项，不能为了统一格式添加虚假原因。
4. **系统包络必须包含主值**：固定情景厚度可能全部落在主值一侧，因此包络显式并入轨 0 常折射率厚度，避免把系统区间误写成不包含基准的置信区间。

- `intrinsic_scenario.py`：固定物性情景下的相位型单参数反演与系统包络；
- `identifiability_audit.py`：将条件数、相关性、触边、留段和轮廓指标统一为“值—阈值—比较符—是否通过”；
- `comparison_report.py`：多模型轨道的显式采纳决策表；
- `dispersion.py` 的 `mode` 参数：兼容旧接口的物理参数开放策略。

1. 架构阶段应提前区分“绝对反射幅值模型”和“条纹相位敏感性模型”，避免把无界面反差的本征情景误写成可直接 Fresnel 反演。

3. 任何“不可辨识”结论都应伴随机器可读证据包，而不是只在论文中给一句定性解释。

## v8 色散坐标多峰谷反演经验

### 算法选型结论

| 步骤 | 最终采用 | 被否决/回退 | 原因 |
|---|---|---|---|
| 色散厚度关系 | 极值级次对 \(g(\tilde\nu)\) 的共享斜率 | 原波数轴固定间距 | 色散下波数间距不再恒定 |
| 多序列融合 | 共享厚度、峰谷/角度独立截距 | 强制共享绝对级次 | 不同界面相位和起始级次未知 |
| 异常处理 | 稳健损失 + MAD审计 | 普通最小二乘 | 漏峰、误峰会放大斜率偏差 |
| SiC主模型 | v8本征色散极值模型 | 常折射率单点 | v8全部稳定性指标通过 |
| Si主模型 | Airy多光束回退 | v8简单极值模型 | 峰谷、留段和Airy一致性均失败 |

### 踩坑记录

1. **选波段与取多极值不能二选一**：极值回归仍必须建立在透明、\(g\)单调的共同合格区内。
2. **漏级恢复需要多数正常间距**：使用相邻 \(g\) 间距稳健中位数作为单位，只有少数漏峰时才能可靠恢复整数倍。
3. **峰谷不一定等价**：Si多光束峰形使峰、谷子模型相差4.77%，证明极值模型不能对所有材料强制采用。
4. **稳定不等于无系统误差**：SiC统计区间较窄，但固定折射率情景仍给出7.37–7.83 µm的模型范围，二者必须分别报告。
5. **多光束一致性应是独立门控**：仅凭极值内部稳定会错误接受Si候选，加入Airy对照后能够正确回退。

### 可复用组件

- `band_eligibility.py`：复折射率驱动的透明区资格模板；
- `extrema_observation.py`：峰谷位置与质量元数据统一封装；
- `dispersion_extrema.py`：色散坐标映射、漏级恢复和情景编排；
- `shared_thickness.py`：多序列共享斜率、独立截距的稳健反演；
- `plot_raw_extrema_evidence`：级次关系与映射间距论文原始图。

### 流程改进建议

1. 模型升级必须同时设计“采用条件”和“回退模型”，不能只比较拟合误差。
2. 统计区间、情景系统范围和参数不可辨识证据应使用不同字段和图表。
3. 对峰谷类模型，应将漏级、边缘极值和异常剔除率纳入自动化测试。

## v9 分析型证据图经验

### 算法选型结论

| 目标 | 最终采用 | 未采用 | 原因 |
|---|---|---|---|
| 论文证据 | 分析图与纯原始图双目录 | 用分析图覆盖原始图 | 原始数据与结论证据用途不同 |
| 阈值标识 | 直接复用求解常量 | 绘图层复制阈值 | 防止模型与图片判据漂移 |
| 复杂说明 | 图外分析框 | 数据区内大段文本 | 避免遮挡曲线和极值 |
| 模型决策 | 基线、候选、最终与系统范围同图 | 只画单一最终点 | 无法解释采用和回退依据 |

### 踩坑记录

1. Microsoft YaHei缺少上标负号字形，分析框中的单位改用`cm^-1`，坐标轴公式继续交由数学字体渲染。
2. SiC与Si厚度尺度差异较大，情景图按材料分别输出，避免同轴压缩Si变化。
3. 对SiC不应显示Airy一致性为失败项，因为其多光束模型并非必需；门控图只显示适用指标。
4. 载流子审计的阈值跨多个数量级，采用对数横轴才能同时看清条件数、相关性和留段指标。

### 可复用组件

- `evidence_plotting.py::_box`：图外结论框与通过/失败边框语义；
- `plot_analysis_evidence`：按材料批量生成分析证据图；
- 归一化门控柱图：不同单位指标统一为“指标值/阈值”；
- 相对基线决策图：不同绝对尺度材料可在同一图中比较模型变化。

### 流程改进建议

1. 绘图函数应只接受已计算结果，禁止在图层重复判断模型。
2. 每个分析结论必须能追溯到CSV/JSON字段或统一阈值常量。
3. 系统测试除文件存在外，还应检查分辨率、图组数量和模型数值未被绘图流程改变。
