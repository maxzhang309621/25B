# 架构方案：2025 B 题碳化硅外延层厚度的确定

> 版本：v6（2026-08-27，论文图防重叠与独立原始证据图，已确认）

## 需求概述

目标是针对红外反射光谱建立外延层厚度测量模型，并完成三项任务：

1. 在仅考虑外延层表面和外延层—衬底界面各一次反射的条件下，建立双光束干涉厚度模型。
2. 对同一块碳化硅晶圆在入射角 \(10^\circ\)（附件 1）和 \(15^\circ\)（附件 2）下的光谱分别估计厚度，交叉验证结果并量化可靠性。
3. 推导多光束干涉出现的必要条件，判断同一块硅晶圆在 \(10^\circ\)（附件 3）和 \(15^\circ\)（附件 4）下是否存在多光束干涉；建立相应厚度模型并计算结果，同时检查碳化硅数据是否也需消除多光束效应。

输入文件均含 7469 个光谱采样点，波数范围约为 \(399.675\)–\(4000.122\ \mathrm{cm^{-1}}\)，中位采样间隔约为 \(0.482\ \mathrm{cm^{-1}}\)。输出包括完整建模说明 `model.md`、可重复执行的 Python 程序、诊断图、分角度厚度结果、联合估计及不确定度/一致性报告。

## 可行性结论

**可行。**

- 技术成熟度：薄膜双光束和多光束干涉均有明确的相位差、反射系数和光程差表达，可由光谱条纹周期反演厚度。
- 数据可得性：四份数据覆盖相同且较宽的波数区间，采样密度足以进行条纹识别、频域诊断和参数拟合；每种材料均有两个入射角，可用于独立估计与联合一致性检验。
- 资源约束：数据规模较小，普通个人计算机即可完成预处理、参数扫描、拟合和重采样不确定度分析。

主要不确定性来自材料折射率随波长和载流子浓度变化，而附件未直接给出浓度或折射率实测值。系统应把折射率色散作为显式输入或待校准关系，并同时报告折射率假设引起的系统误差，避免把厚度结果误报为唯一精确值。

## 数据流与接口约定

### 数据流

Excel 光谱 → 格式与异常检查 → 基线/噪声分离 → 条纹候选区间 → 双光束周期与厚度初值 → 多光束诊断 → 受物理约束的模型拟合 → 双角度联合校验 → 不确定度分析 → 表格、图片和 `model.md`。

### 核心数据约定

- 波数统一记为 \(\tilde\nu\)，单位为 \(\mathrm{cm^{-1}}\)；内部计算厚度统一使用 \(\mathrm{cm}\)，展示时转换为 \(\mu\mathrm{m}\)。
- 入射角为真空/空气侧相对法线的角度；折射角由折射关系计算，不直接用入射角替代。
- 每份处理后的光谱用同一结构表示：`wavenumber_cm1`、`reflectance_pct`、`angle_deg`、`material`、`source_file`。
- 折射率接口接收材料和波数数组，返回实部及可选虚部；常折射率、色散关系和敏感性区间共享统一接口。
- 厚度估计结果至少包含：`thickness_um`、置信区间、使用波数区间、有效条纹数、拟合误差、折射率设定、角度和模型类型。

### 模型层级

1. **双光束层**：由两束反射光的光程差和相位差得到反射率振荡关系；先利用条纹间隔获得厚度初值，再在允许折射率变化时联合校正。
2. **多光束层**：将外延层内往返反射形成的相干光束求和，使用界面反射强度、相干长度、吸收和仪器分辨率形成必要条件；通过高阶谐波、尖锐峰形和残差结构判断是否必须采用该层。
3. **验证层**：同一晶圆的两个角度应得到相容厚度；若不相容，则按折射率色散、基线偏差、条纹误检和多光束效应依次进行误差归因。

## 风险与外部依赖

- **折射率数据风险**：厚度与折射率强耦合；若无可靠材料色散参数，只能给条件厚度及敏感性区间。算法选型阶段需检索公开材料光学常数及其适用温度、掺杂和波段。
- **可辨识性风险**：仅由反射率可能难以同时唯一确定厚度、折射率、吸收和界面反射参数；需要物理边界、两角度共享厚度及分层拟合降低退化。
- **相干性风险**：多光束“存在”与“在仪器中可观察”不同，必须同时考虑光源相干长度、光谱分辨率、吸收和厚度不均匀。
- **预处理偏差**：过度平滑或基线扣除会改变峰位和谐波，应保留原始数据并做多参数稳定性检查。
- **依赖**：Python 数值计算、表格读取、科学计算和绘图库；均可离线运行，不依赖第三方在线服务。

## v3 波长—载流子浓度耦合折射率变更

### 架构结论

1. 将常数折射率升级为复折射率状态函数
   \(\tilde n=\tilde n(\tilde\nu,N,T,\text{材料状态})\)，显式体现题目指出的波长与掺杂载流子浓度影响。
2. 分别建立外延层 \(\tilde n_{\mathrm{epi}}\) 与衬底
   \(\tilde n_{\mathrm{sub}}\)：前者控制传播相位，两者之差控制界面反射幅值与相位。
3. 折射率模型分为晶格/本征色散背景、自由载流子修正和可选吸收项。论文物性关系提供函数形状、参数先验与适用区间，附件只校准一至两个可辨识的载流子相关参数。
4. 同一晶圆的 10°/15° 光谱共享厚度及材料参数，各角度只保留基线、振幅和相位偏置等仪器干扰参数。
5. 主厚度由透明区相位确定，吸收区主要用于约束载流子响应与检验模型。若浓度不可辨识，则输出分档掺杂情景下的厚度范围，不报告虚假的唯一浓度。

### 新增模块与数据流

| 模块 | 职责 | 所需算法/逻辑/架构类型 |
|---|---|---|
| `dispersion.py` | 计算 SiC/Si 外延层与衬底的波数—载流子复折射率，保存论文来源和适用条件 | 物理先验、材料策略模式、复介电函数 |
| `joint_calibration.py` | 联合两个角度估计共享厚度和少量材料修正参数 | 分层参数模型、受约束联合反演、可辨识性诊断 |
| `uncertainty.py` 扩展 | 分离统计、论文物性和未知掺杂三类误差 | 区块重采样、先验扰动、情景分析 |

数据流变更为：

论文物性与掺杂先验 → 外延层/衬底复折射率 → 常数模型厚度粗估 →
双角度共享厚度与低维材料参数联合校准 → 连续波段留出与可辨识性门控 →
统计/物性/掺杂不确定度 → 厚度、折射率曲线与证据报告。

### 分层反演与回退

1. **常数基线层**：保留当前结果，用于干涉级次初值与回归对照。
2. **本征色散层**：固定载流子修正，只引入论文波长色散关系。
3. **载流子耦合层**：在论文先验边界内开放少量载流子相关参数，禁止逐波数自由拟合 \(n,k\)。
4. **外延层—衬底层**：分别计算两层光学常数，以物理界面系数替代无约束有效反射率。
5. **情景层**：若厚度与载流子参数相关系数绝对值过高，则固定低/中/高掺杂情景，将结果差异计入系统误差。

### v3 验收标准

1. SiC/Si 主波段内复折射率有限，实部为正、吸收非负；晶型、晶向、温度、掺杂类型、适用波段与论文来源可追溯。
2. 常数折射率退化路径与 v2 数值一致，现有测试全部通过。
3. 匹配实测噪声的合成数据中，给定物性先验时联合厚度恢复误差不超过 2%；外延层与衬底折射率相等时界面反射正确退化。
4. 双角度独立厚度相对差不超过 2%；连续波段留出时厚度变异系数不超过 1%，任一留段相对全谱偏移不超过 2%。
5. 更复杂层级的留出误差相对低一级至少改善 10%，且厚度与任一材料修正参数相关系数绝对值小于 0.95；否则回退为情景分析。
6. 输出同时给出常数基线、本征色散、载流子耦合三层厚度，以及 \(n(\tilde\nu)\)、\(k(\tilde\nu)\)、掺杂情景、参数来源、统计区间和系统误差。

## v5 SiC 载流子浓度反演增强

### 需求与可行性

目标是优先增强附件 1/2 的 SiC 物理反射率模型，使外延层/衬底载流子浓度反演具有可审计的可信区间和更严格的可辨识性结论，再将同一架构复用到 Si。由于附件 2 反射率超过 100%，且题目未提供晶型确认、偏振、温度、迁移率或独立浓度测量，本变更不能承诺唯一浓度点估计；可行目标是“可靠区间、单侧界限、浓度等级或明确拒绝估计”。

### 模块划分

| 模块 | 职责 | 所需算法/逻辑/架构类型 |
|---|---|---|
| `dispersion.py` 扩展 | 区分晶轴方向、晶格/载流子/高阶吸收贡献，允许物性不确定性传播 | 张量复介电函数、分层物理先验 |
| `instrument_response.py` | 表示共享光谱响应、角度通量、波数/角度偏差、分辨率与相关噪声 | 受约束仪器模型、剖面消元 |
| `carrier_band_policy.py` | 分离厚度敏感透明区与浓度敏感声子—等离子体区 | 材料策略、物理灵敏度评分 |
| `carrier_inference.py` | 编排厚度锚定、单浓度条件反演、双浓度联合反演和逐级回退 | 分阶段受约束反演、状态机 |
| `identifiability.py` | 计算浓度灵敏度独立性、厚度补偿、参数区间和留段稳定性 | 灵敏度矩阵、轮廓区间、门控规则 |
| `uncertainty.py` 扩展 | 传播噪声、仪器响应、迁移率和物性先验的不确定性 | 区块重采样、情景包络 |
| `main.py` | SiC 优先执行增强路径；不可辨识时抑制点估计 | 条件输出、审计流水线 |

### 分阶段数据流

1. **数据资格审查**：检查绝对反射率物理范围、探测器分段、噪声和重复性；不合格时切换“相对谱形模式”。
2. **厚度锚定**：仅用透明相位波段确定厚度及其区间，不让慢变载流子吸收改变干涉级次。
3. **仪器层校准**：在载流子弱敏感波段估计共享响应与角度通量，禁止每个角度的任意基线完全吸收载流子谱形。
4. **浓度敏感通道**：使用 SiC 声子—等离子体过渡区及吸收尾区约束自由载流子响应；未建模吸收不得只靠硬掩膜处理。
5. **单浓度条件反演**：先固定衬底情景估计外延层浓度，再固定外延层情景估计衬底浓度。
6. **双浓度联合反演**：仅当两层浓度的光谱灵敏度方向足够独立时同时开放。
7. **区间与回退**：根据可辨识性输出双浓度区间、单浓度条件区间、单侧界限、浓度等级或不可辨识结论。

### 参数开放原则

- 跨角度共享：厚度、两层浓度、晶体状态、温度、表面/过渡结构和共享仪器响应。
- 角度专属但有界：通量因子、实际角度微小偏差和噪声尺度。
- 默认固定并传播不确定性：载流子类型、有效质量、迁移率关系、晶格参数和仪器分辨率。
- 迁移率、浓度梯度、粗糙层和过渡层只能逐项开放；每增加一个自由度都必须重新通过留段预测与区间门控。

### 输出契约

- 只有门控通过时，主表写入 `n_epi_cm3`、`n_sub_cm3` 点估计。
- 不可辨识时点估计必须为 `null`，另行输出对数浓度区间、单侧界限或情景包络。
- 结果至少包含：`identifiability_level`、两层浓度区间、厚度—浓度补偿指标、信息波段、边界命中、仪器模式和回退原因。
- v4 可视化同步显示浓度区间与可辨识等级，候选优化值只进入诊断附件，不进入主结论。

### v5 验收标准

1. 合成 SiC 数据中，在厚度、浓度、仪器增益和噪声均扰动时，外延层浓度误差不超过 0.3 dex；不可辨识样本误报率低于 5%。
2. 双浓度定量输出要求：两层灵敏度方向相似度低于 0.90、浓度相关系数绝对值低于 0.85、90% 区间宽度均不超过 0.6 dex且不触边。
3. 单浓度条件输出的 90% 区间宽度不超过 1.0 dex；否则继续回退为单侧界限或浓度等级。
4. 相对最佳固定情景，连续留段预测误差至少改善 10%；删除任意连续 10% 波段后浓度中心变化不超过 0.25 dex。
5. SiC 浓度敏感区残差不再依赖硬掩膜，结构化残差显著下降；厚度连续波段 CV 中期目标从 8.69% 降至不超过 3%。
6. 仪器响应扰动 ±10% 的合成测试中，浓度偏移不超过 0.5 dex，且相对无仪器层模型至少改善 50%。
7. 若真实附件仍信息不足，程序必须正确输出条件区间或不可辨识，而非强行满足点估计门槛。
8. 原 15 项测试、厚度和多光束判定不得无证据退化；新增不少于 6 项浓度区间、仪器扰动和回退测试。

### 风险与外部数据

- 仅凭两条近法向反射谱可能无法区分外延层和衬底浓度；正确拒绝输出是合格结果。
- 附件 2 的 >100% 反射率意味着绝对标定不足；增强模型可约束仪器响应，但不能替代缺失的参考镜、背景谱和重复测量。
- 若可补充数据，优先级依次为：样品/参考/背景原始谱、Hall 或 C–V 浓度、更大角度跨度、已知偏振、晶型晶向与温度。
