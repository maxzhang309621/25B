# 高教社杯数模论文 — 可填充结构模板

**排版（强制）**：大标题黑体小三并居中（Word 标题 1）；二级/三级为标题 2/3（黑体小四/五号）；正文宋体五号；英文 Times New Roman 五号；图居中、图题在下；表居中、表名在上，表头与数据间黑色分割线；段落两端对齐、首行空两格；公式居中且详细具体（正规公式对象）；文献用 Zotero 正规样式。详见 [writing-standards.md](writing-standards.md)。
