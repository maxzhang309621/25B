# 交稿前质检清单

## A. 结构完整性

- [ ] 标题含方法或对象，非空泛「研究」
- [ ] 摘要含总起 + 分问 + 关键词
- [ ] 问题重述与题面各问交付物对齐
- [ ] 问题分析覆盖每一问且说明问间递进
- [ ] 假设 3–8 条且可操作
- [ ] 符号表与正文一致
- [ ] 每问均有：建模 → 求解 → 结果（表/图）
- [ ] 至少一类检验/灵敏度/对照
- [ ] 评价含优点与缺点改进
- [ ] 参考文献真实可查
- [ ] 附录含程序或长表；题面附件已说明

## B. 摘要竞争力

- [ ] 「针对问题一/二/三」结构清晰
- [ ] 方法名可检索（算法/方程/原则）
- [ ] 关键数值齐全且与正文一致
- [ ] 无抄题、无空话段

## C. 学术规范

- [ ] 公式编号与引用正确
- [ ] 图题表题完整、单位明确
- [ ] 术语与符号全文统一
- [ ] 无伪造数据/文献
- [ ] 未剽窃优秀论文原文

## C2. 排版格式（用户强制规则）

- [ ] 一级标题：黑体小三、**居中**；并用 Word **标题 1**
- [ ] 二级标题：黑体小四；Word **标题 2**
- [ ] 三级标题：黑体五号；Word **标题 3**
- [ ] 正文：宋体五号；英文/数字：Times New Roman 五号
- [ ] 段落：两端对齐；普通段首行空两格
- [ ] 公式/图/表后的解释性文字：不另起段、首行不空两格
- [ ] 图像居中，图题在下方
- [ ] 表格居中，表名在上方；**表头与数据之间有黑色分割线**
- [ ] 公式居中；正规公式对象（Word 公式/LaTeX）；内容详细具体
- [ ] 参考文献：Zotero 正规样式导出，条目完整

## D. 竞赛合规（提醒用户自行核对当届通知）

- [ ] 页数、字体、匿名、承诺书等格式
- [ ] 指定表格字段与 result 文件名
- [ ] 禁止事项（如违规引用网络等）已规避

## 审校时的优先级

1. 摘要与结果一致性  
2. 题面强制输出是否齐全  
3. 模型逻辑链条是否闭环  
4. 文风与版式细节
