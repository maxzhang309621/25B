# 摘要写作指南（对标优秀论文）

## 标准骨架

```
[总起 2–4 句]
针对问题一，…（方法）…（关键数值）…
针对问题二，…（方法）…（关键数值）…
针对问题三，…（方法）…（关键数值）…
关键词：…；…；…
```

也可写作「摘  要」二字中间空格（部分优秀论文排版习惯）；内容结构不变。

## 总起段写什么

三句话内覆盖：

1. **对象**：系统/场景是什么  
2. **视角**：规划 / 传热 / 光学效率 / 调度 / 评价等  
3. **交付**：给出方案、参数或指标计算结果  

示例模式（勿照抄语料原文）：

> 本文从[优化/规划/机理建模]角度，建立[模型名]，采用[算法]，研究[对象]的[问题]，并给出[方案/参数/指标]结果。

## 「针对问题×」段写法

每问一段，建议句序：

1. 该问任务本质（计算 / 反问题优化 / 约束放松）  
2. 关键建模步骤（坐标系、方程、目标与约束）  
3. 求解手段（算法或原则名）  
4. **2–5 个硬结果**（最优值、效率、件数、厚度、坐标等）  
5. 可选：指向「见表× / 附录」

硬结果缺失时写 `【待填】`，不要捏造。

## 关键词

- 数量 **3–6**  
- 优先：**模型名、算法名、核心机理词、对象词**  
- 分隔：中文分号 `；` 或空格（全文统一）  
- 避免：过于宽泛的「数学建模」「优化问题」单独作关键词

## 从语料抽象的句式模式（可仿不可抄）

**调度类**

> 针对情况一：…较为简单。首先利用…刻画…。规划目的是…。该问题为 NP 问题，故采用…模拟求局部最优。选取「原则A」「原则B」…结果为…件，效率为…。

**机理+优化类（传热/光学等）**

> 针对问题一，建立…方程组/效率模型，用…数值方法得到…分布/功率为…。针对问题二，以…为目标、以…为决策变量建立单目标模型，用…算法求得…为…。

**递进优化类**

> 针对问题三，在问题二基础上允许…不同，采用…策略将决策变量降维为…，用…搜索得到…。

## 摘要质检（写完必过）

- [ ] 评阅人只读摘要能否知道每问用了什么方法  
- [ ] 每问是否至少 1 个具体数值或明确参数方案  
- [ ] 关键词能否从摘要方法句中抽到  
- [ ] 与正文最终结果是否一致  
- [ ] 有无大段背景/政策空话（应删除）  
- [ ] 长度：通常约 **600–1000 字**（随题量增减）；过短缺结果，过长挤占首页
